## 1. Claim 15: "the first timeline starts on the first position update (start or seek), not at init"
Document (examples/eligian-tour/ELIGIUS_EXECUTION_MODEL.md:207-209, §7b):
  "At init the **first** timeline (the hub) starts on the first position tick; in
   headless jsdom nothing ticks until the position moves (`eligian smoke` seeks every
   timeline to each of its event boundaries)."
Spec observable (spec.md FR-010 claim 15): "after init() and before the first faked
  animation frame there is no on enter entry of the first timeline; after the first frame
  has ticked the position there is."
Observed (fake timers, FR-010a; a 1 s raf timeline with on enter / on leave):
  - after init():                                  log []                       (no on enter: agrees)
  - start(), fake clock advanced 0 ms (no frame):  log ["A-enter","A-start"]   position 0
  - fake clock advanced to 99 ms (still no tick):  log ["A-enter","A-start"]   position 0
  - fake clock advanced to 150 ms (first tick):    log ["A-enter","A-start"]   position 0.2
  So on enter runs inside start(), BEFORE any animation frame: RafPositionSource.startTicking
  calls setPosition(getPosition()) (eligius dist/engine-factory-*.mjs, "startTicking()",
  BasePositionSource.setPosition invokes the position callbacks when active), and that
  position update starts the first timeline. The first raf frame only moves the position on.
  Without playback, seek(0) right after init() also starts it (the position does not move:
  0 -> 0); claims 12 and 14 use that as their precondition, and claim 15's second probe
  asserts it.
Corrected statement for T025: the first timeline does not start at init(); it starts on the
  first position update, which start() emits immediately (before any animation frame) and
  which a seek (also seek(0)) emits without playback. "nothing ticks until the position
  moves" becomes "nothing starts until start() or a seek".
Assertion in the spec: no A-enter after init(); A-enter present after start() with the fake
  clock at 0 ms and position 0; after one tick position > 0 and still exactly one A-enter;
  second probe: init() -> none, seek(0) -> A-enter.
