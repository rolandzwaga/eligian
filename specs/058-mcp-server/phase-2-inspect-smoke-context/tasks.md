## How to read this list

- Tasks `T001…` are grouped into **ordered groups**. A group starts only when the previous group is done.
- **[P]** = parallel-safe inside its group: the task creates **new files only**, disjoint from every other [P] task of that group. A task that edits an existing file (a `package.json`, an `index.ts` / `mcp.ts` barrel, an `esbuild.mjs`, a workflow, `main.ts`, `smoke-runner.ts`, `generate-knowledge.ts`, a spec file created by an earlier task, `AGENTS.md`) is never [P] and runs in the order written.
- Each task names the files, the **failing test written first** (spec file, `describe` / `it` names, exact assertions), the implementation intent, and the **verify** command(s). Canonical order per task: failing test (run it, see it red) → implement → `pnpm check` (Biome autofix) clean → the named tests pass. Effect code (`packages/cli/src/mcp/**`, `packages/cli/src/check/**`, `packages/cli/src/compile-file.ts`, `packages/language/src/compiler/pipeline/**`) additionally `pnpm effect:check:cli` / `pnpm effect:check:language` → 0 errors / 0 warnings.
- Read `specs/TESTING_GUIDE.md` before writing the first test (Constitution XXV). Language tests that validate in-memory documents use `createTestContext()` / `getErrors()` / `getWarnings()` / `setupCSSRegistry()` and the `DiagnosticSeverity` enum from `packages/language/src/__tests__/test-helpers.ts`; no magic severity numbers. Tests that need a real layout / CSS / media file use `checkFiles([...])` over committed fixtures (plan "Constitution check").
- Paths: Windows backslash paths for every file tool (`F:\projects\eligius\eligian\...`); POSIX paths in Bash (`/f/projects/eligius/eligian/...`). `$SCRATCH` = the executing session's scratchpad directory, written with forward slashes and a drive letter (`export SCRATCH=C:/Users/<user>/AppData/Local/Temp/claude/<session>/scratchpad`); never `/tmp`. Commands run from the repo root in Bash. pnpm only (the eval harness, SC-012 and the FR-056 runs use `npm` inside temp *user* projects on purpose, plan "Constitution check" VIII).
- **`BASE`** = `specs/058-mcp-server/phase-2-inspect-smoke-context/baseline/`. Raw outputs that the spec or plan says go "in `compliance.md`" are saved by the task to `BASE/<name>.txt` (a new file per task, so [P] tasks never share a file). The comply stage quotes them.
- **Built-artifact precondition**: CLI tests resolve `@eligian/language` and `@eligian/language/mcp` to the built `packages/language/dist/index.cjs` and `dist/mcp/index.cjs`: two bundles with **two Langium singletons** (plan P1).
