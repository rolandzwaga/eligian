## How to read this list

- Tasks `T001` … are grouped into ordered **groups**. A group starts only when the previous group's gate is green (plan "Gates": `pnpm build`, `pnpm typecheck`, `pnpm typecheck:tests`, `pnpm run ci`, the scoped vitest run of the group's specs, and `pnpm effect:check:cli` 0/0/0 for every group that touches `packages/cli/src/`).
- **[P]** marks a task that creates only NEW files, disjoint from every other task of its group; the [P] tasks of a group run in parallel. A task without [P] runs alone, in the listed order. Every task that edits an existing or shared file (`gate.ts`, `main.ts`, `instructions.ts`, `prompts.ts`, `server.ts`, `harness.ts`, `transcript.ts`, `assert.ts`, `agents.ts`, an existing spec, `package.json`, `server.json`, the plugin JSON files, `run.ts`, README, CHANGELOG, `AGENTS.md`, `roadmap.md`) is unmarked.
- Every task follows the repo order: **write the failing test first and run it red → implement → `pnpm check` clean (Biome autofix, 0 errors, 0 warnings) → the verify command green**. Every task that touches `packages/cli/src/` also runs `pnpm effect:check:cli` with 0 errors, 0 warnings, 0 messages gated (the Effect files of this phase: `gate.ts` imports `Effect`, `gate.ts:18`; `harness.ts` imports `Schema`, `harness.ts:11`; `prompts.ts` and `server.ts` use `ai.McpServer`; `interview.ts` will import `Schema`).
